# Product requirement: OpenClaw Skill Store

Build a polished, deployable web application for discovering and installing
OpenClaw Skills.

## Technical constraints

- Start from an empty Git repository.
- Use semantic HTML, modern CSS, and vanilla JavaScript with no runtime dependency.
- The site must work as static files on GitHub Pages.
- Do not use remote images, external fonts, API keys, databases, or a backend.
- Include a Node-based deterministic validation suite with no third-party dependency.
- Include a GitHub Pages deployment workflow.
- Use directory-style routes or a single-page implementation that survives a page refresh.

## Required user-facing features

1. Marketplace landing page with a strong OpenClaw visual identity and responsive layout.
2. At least eight realistic Skills across multiple categories.
3. Search by name, author, slug, and description.
4. Category filters with a visible result count and useful empty state.
5. Skill detail dialog containing:
   - version, author, downloads, rating, and last update;
   - complete description;
   - requested permissions;
   - security/risk status;
   - a valid-looking OpenClaw `SKILL.md` manifest preview.
6. Install flow containing:
   - security review;
   - permission confirmation;
   - install command;
   - installed state persisted in `localStorage`.
7. Keyboard accessibility, focus management, Escape-to-close, and reduced-motion support.
8. Architecture and provenance section explaining that this application was generated by
   ForgeLoop and linking to the autonomous-system repository.

## Quality requirements

- No horizontal overflow at 375px viewport width.
- Clear loading/empty/installed/dialog states.
- No inline event-handler attributes.
- No secret-like values.
- Validation must cover data integrity, required DOM hooks, accessibility contracts,
  GitHub Pages files, and the main user-flow functions.
- README must explain local usage, validation, deployment, and generated provenance.

## Delivery

The generated repository must contain the complete application, tests, README,
architecture document, task plan, progress log, automation evidence, and Git history.
